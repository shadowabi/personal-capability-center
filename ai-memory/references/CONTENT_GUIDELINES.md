# 内容存储指南

## 核心原则

**能力提炼优先**

当用户提供对话内容时，应该按照"能力提炼"的方式进行总结和整理，提取出对话中体现的**可复用的能力**，而不仅仅是记录"知识点"。

**与笔记工具的区别**：
- 笔记工具：存的是"知识点"（如"执行意图是什么"）
- 能力中心：存的是"能力"（如"掌握了执行意图，可应用于减肥、学习、工作习惯"）

**对话即能力**：
当AI使用"引导式思维"与你交互时，对话本身就变成了深度思考的过程。这种对话沉淀下来，就是你的能力。

## 适用场景

### 场景1：能力提炼（推荐）

从对话中提炼出**可复用的能力**。

**✅ 正确做法：提炼能力而非总结对话**

```python
title = "短视频自控能力"
summary = "掌握了执行意图、预先承诺、中断锚点等行为设计方法，可用于各种自控场景"
details = """掌握的能力：

1. 执行意图（If-Then计划）
- 为什么：预先设定"如果...那么..."的具体行为，减少决策消耗
- 怎么用：IF 看完第10个视频 THEN 立刻关闭APP
- 可复用：减肥、学习、工作习惯、短视频、游戏等

2. 预先承诺机制
- 为什么：主动设定惩罚增加违约成本
- 怎么用：如果超标（>10个视频），选择一项执行：10个俯卧撑 / 捐1元 / 公开承认
- 可复用：任何需要自我约束的场景

3. 中断锚点设置
- 为什么：用具体数字或动作作为停止的检查点
- 怎么用：每刷完5个视频，站起来喝口水
- 可复用：短视频、游戏、社交媒体等

4. 记录与复盘方法
- 为什么：数据化追踪形成反馈闭环
- 怎么用：每天记录"计划刷多久 → 实际刷了多久 → 超时了吗"
- 可复用：任何需要追踪的行为"""
```

**❌ 错误做法：只是对话总结**

```python
# details = "今天讨论了如何控制刷短视频，AI教了我几个方法，包括执行意图、预先承诺、中断锚点、记录复盘等..."
```

**为什么错误**：这是"知识点"，不是"能力"。读者不知道"为什么"、"怎么用"、"可复用"。

---

### 场景2：用户提供的总结性内容

当用户提供的内容本身就是总结性、结构化的文本时，应该直接使用完整原文作为`details`字段，**不要再次"总结"**，否则会丢失重要细节。

```python
title = "投资策略评估"
summary = "投资策略：50%沪深300 + 50%量化板块"
details = """策略框架：
资金分配：
- 50%沪深300ETF（510300）：分散风险，获取市场平均收益
- 50%量化板块：根据量化信号选择板块，追求超额收益

目标收益：
- 年化收益：沪深300 + 10%+
- 止损规则：比大盘多亏20%清仓

优化建议：
1. 建立详细记录（6-12个月验证期）
2. 调整补仓策略（不追高）
3. 优化清仓触发条件
4. 增加板块分散度"""
```

## 数据库字段说明

| 字段 | 用途 | 长度建议 |
|------|--------|------------|
| **title** | 一句话描述主题，快速识别 | 50-100字符 |
| **summary** | 简要概括，快速浏览 | 100-200字符 |
| **details** | 完整内容或结构化要点，保留所有细节 | 根据内容需要，不限长度 |

## 实践建议

### 能力提炼的核心原则

1. **提炼"为什么"** - 为什么这个方法有效？背后的原理是什么？
2. **提炼"怎么用"** - 具体如何应用？步骤是什么？
3. **提炼"可复用"** - 这个能力可以用于哪些场景？
4. **结构化呈现** - 使用项目符号、编号等结构化格式，按"为什么、怎么用、可复用"组织

### AI生成指导

当AI需要为`details`字段生成内容时，应该：

```python
# AI生成details的prompt示例
"""
请从以下对话中提炼出可复用的能力，按照以下结构组织：

掌握的能力：
1. [能力名称]
- 为什么：[为什么这个方法有效]
- 怎么用：[具体如何应用]
- 可复用：[可用于哪些场景]

2. [能力名称]
- 为什么：[为什么这个方法有效]
- 怎么用：[具体如何应用]
- 可复用：[可用于哪些场景]
"""
```

### 内容存储原则

1. **结构化要点优于总结** - 使用项目符号、编号等结构化格式
2. **保留量化数据** - 数字、百分比、日期等不要省略
3. **保留决策逻辑** - 为什么、如何、如果等推理过程
4. **保留上下文** - 相关的背景信息、约束条件等
5. **避免过度压缩** - 只在原始内容冗长杂乱时才总结

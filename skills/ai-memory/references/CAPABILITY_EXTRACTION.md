# 能力提炼指南

## 什么是能力提炼？

**能力提炼**是指从对话中提取出**可复用的能力**，而不仅仅是记录"知识点"。

### 与笔记工具的区别

| 维度 | 笔记工具 | 能力中心 |
|------|---------|---------|
| **存储对象** | 知识点 | 能力 |
| **核心问题** | "这是什么？" | "是什么能力"、"深刻洞察"、"如何转变" |
| **举例** | "执行意图是什么" | "掌握了执行意图，可应用于减肥、学习、工作习惯" |
| **复用性** | 需要重新学习 | 直接复用方法 |

---

## 能力提炼的三要素

每个能力必须包含以下三个要素：

### 1. 能力定义

**目的**：让读者理解这个能力的本质是什么（抽象层）。

**例子**：
```
执行意图（If-Then计划）
- 能力定义：预先设定"如果...那么..."的具体行为，减少决策时的意志力消耗
```

### 2. 体现在深刻洞察

**目的**：用具体场景说明这个能力如何体现（表象层）。

**例子**：
```
执行意图（If-Then计划）
- 体现在深刻洞察：
  - IF 看完第10个视频 THEN 立刻关闭APP
  - IF 吃完晚饭 THEN 立刻刷牙（不夜宵）
```

### 3. 认知转变过程

**目的**：展示从错误认知到正确能力的完整转变路径。

**例子**：
```
执行意图（If-Then计划）
- 认知转变过程：
  - 原本认知：靠意志力停止刷短视频
  - 引导提问："为什么总是停不下来？"
  - 突破点：决策发生在刷的时候，不是停止的时候
  - 新认知：需要在决策点预设触发条件
---

## 能力提炼的方法

### 方法1：识别关键转折点

**什么是关键转折点？**
- 用户的问题从模糊到清晰
- 用户从不知道方法到知道方法
- AI的判断或原理说明

**示例**：
```
用户：这没有解决根本问题，我希望能聚焦于怎么让我刷短视频后还保持自控力
AI：你抓住了问题的核心。环境的改变是外力，而你要的是内在的自控力。
```

**关键转折**：从环境改变到内在自控

**对应能力**：执行意图、预先承诺等内在自控方法

---

### 方法2：提取核心概念

**什么是核心概念？**
- AI解释的原理、方法、技巧
- 带有定义的内容

**示例**：
```
AI：这里有一个关键概念——执行意图（Implementation Intentions）：
我们通常制定的是："我要刷1小时就停下来" ← 这是目标意图
真正有效的是："如果我刷完一个视频想要继续刷，那么我就放下手机去刷牙" ← 这是执行意图
```

**核心概念**：执行意图

---

### 方法3：总结用户掌握的方法

**如何总结？**
- 用户说"试试"、"好的"之后，前面讨论的内容就是用户掌握的方法
- 最终方案是用户掌握的能力

**示例**：
```
AI：短视频自控方案（定量版）：
1. 数量限制：每晚最多10个短视频
2. 执行意图：IF 看完第10个视频 THEN 立刻关闭APP
3. 记录机制：每天记录
4. 预先承诺：如果超标，选择惩罚

用户：非常好，看来我们已经达成了一个共识
```

**用户掌握的能力**：
- 数量限制方法
- 执行意图
- 记录机制
- 预先承诺机制

---

### 方法4：识别可复用场景

**如何识别？**
- 方法背后的原理是什么
- 这个原理可以用于哪些场景

**示例**：
```
执行意图：预先设定"如果...那么..."的具体行为

可复用场景：
- 减肥：IF 吃完晚饭 THEN 立刻刷牙（不夜宵）
- 学习：IF 看到手机 THEN 放到另一个房间（不玩手机）
- 工作习惯：IF 完成一个任务 THEN 记录到待办清单
```

## 能力提炼的结构

### 推荐格式

```
掌握的能力：

1. [能力名称]
能力定义：[这个能力的本质是什么]
体现在深刻洞察：
- [用具体场景说明这个能力]

认知转变过程：
- 原本认知：[开始时的错误认知]
- 引导提问："[AI提出了什么关键问题]"
- 突破点：[在哪个时刻突然明白了]
- 新认知：[最终形成的新认知]

---

2. [能力名称]
能力定义：...
体现在深刻洞察：...
认知转变过程：...
```

### 示例

```
掌握的能力：

1. 执行意图（If-Then计划）
能力定义：预先设定"如果...那么..."的具体行为，减少决策时的意志力消耗
体现在深刻洞察：
- IF 看完第10个视频 THEN 立刻关闭APP
- IF 吃完晚饭 THEN 立刻刷牙（不夜宵）

认知转变过程：
- 原本认知：靠意志力停止刷短视频
- 引导提问："为什么总是停不下来？"
- 突破点：决策发生在刷的时候，不是停止的时候
- 新认知：需要在决策点预设触发条件

---

2. 预先承诺机制
能力定义：主动设定惩罚增加违约成本
体现在深刻洞察：
- 如果超标（>10个视频），选择一项执行

认知转变过程：
- 原本认知：靠自觉自控
- 引导提问："如果没做到，有什么后果？"
- 突破点：外部约束比意志力更可靠
- 新认知：主动增加违约成本
```

## AI生成能力提炼的Prompt

### Prompt模板

```python
"""
请从以下对话中提炼出可复用的能力，按照以下结构组织：

掌握的能力：

1. [能力名称]
能力定义：[这个能力的本质是什么]
体现在深刻洞察：
- [用具体场景说明这个能力]

认知转变过程：
- 原本认知：[开始时的错误认知]
- 引导提问："[AI提出了什么关键问题]"
- 突破点：[在哪个时刻突然明白了]
- 新认知：[最终形成的新认知]

---

2. [能力名称]
能力定义：...
体现在深刻洞察：...
认知转变过程：...

要求：
1. 识别对话中的关键转折点
2. 提取AI解释的核心概念
3. 总结用户掌握的方法
4. 按照推荐格式组织

对话内容：
{conversation_text}
"""
```

### 示例

```python
from scripts.ai_memory import AIMemory
from openai import OpenAI

# 连接数据库
memory = AIMemory()

# 生成能力提炼
client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {
            "role": "system",
            "content": """请从以下对话中提炼出可复用的能力，按照以下结构组织：

掌握的能力：

1. [能力名称]
能力定义：[这个能力的本质是什么]
体现在深刻洞察：
- [用具体场景说明这个能力]

认知转变过程：
- 原本认知：[开始时的错误认知]
- 引导提问："[AI提出了什么关键问题]"
- 突破点：[在哪个时刻突然明白了]
- 新认知：[最终形成的新认知]"""
        },
        {
            "role": "user",
            "content": conversation_text
        }
    ]
)

details = response.choices[0].message.content

# 保存到数据库
memory.add_conversation(
    title=extract_title(conversation_text),
    summary=extract_summary(conversation_text),
    details=details,
    embedding=generate_embedding(conversation_text),
    tags=['行为设计', '自我管理'],
    importance=8,
    word_count=len(conversation_text)
)
```

## 常见问题

### Q1: 如果对话中没有明确的能力怎么办？

**A**: 如果是对话记录（如闲聊、日常交流），可以：
- 保存为"对话记录"，不进行能力提炼
- 或者尝试提取对话中的知识点或信息

### Q2: 能力提炼是否适用于所有对话？

**A**: 不是。适用场景：
- ✅ AI使用"引导式思维"的对话
- ✅ 涉及方法、技巧、原理的讨论
- ✅ 用户明确表示"试试"、"好的"、"我理解"的对话

不适用场景：
- ❌ 闲聊、日常交流
- ❌ 纯信息查询（如"天气怎么样"）
- ❌ 一次性任务（如"帮我写一个函数"）

### Q3: 如何判断是"知识点"还是"能力"？

**A**: 问自己三个问题：
1. 这个内容是否包含"能力定义"？
2. 是否有"深刻洞察"（具体应用场景）？
3. 是否有"认知转变过程"（从错误到正确的路径）？

如果三个问题都是"是"，则是"能力"。
如果缺少任何一个要素，则是"知识点"。

## 总结

### 能力提炼的核心

1. **不是记录知识点，而是提炼能力**
2. **包含三要素：能力定义、深刻洞察、认知转变**
3. **按推荐格式组织：能力名称 + 能力定义 + 深刻洞察 + 认知转变**
4. **使用AI生成时，提供清晰的prompt**

### 能力提炼的价值

1. **可复用**：直接应用到其他场景
2. **可理解**：理解能力的本质和应用场景
3. **成体系**：从对话到能力，从能力到成长
4. **可视化**：清晰展示个人能力成长
